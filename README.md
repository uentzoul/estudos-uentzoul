# Estudos Uentzoul

Central de estudos de Psicologia 2026/2.

O `index.html` é a aplicação responsiva. Os áudios de cada episódio devem ficar em `audios/` com os caminhos indicados no catálogo. Os visitantes podem baixar somente o episódio desejado.

Para ativar um endereço público, configure GitHub Pages na branch `main`, diretório `/ (root)` em **Settings → Pages**.
